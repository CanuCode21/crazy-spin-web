# Crazy Spin Web

Simulatore web interattivo ispirato ai game show con ruota della fortuna e mini-giochi bonus, sviluppato con **Java / Spring Boot** per il backend e **HTML5, CSS3 e JavaScript** per l'interfaccia utente.

## Funzionalità principali
- **Ruota principale interattiva:** simulazione dei giri con gestione delle puntate, moltiplicatori e calcolo automatico delle vincite.
- **Mini-giochi bonus:** modalità extra attivabili dall'esito della ruota con logiche dedicate lato server.
- **Gestione saldo e storico:** aggiornamento in tempo reale del bilancio del giocatore e tracciamento delle giocate recenti.
- **Architettura Client-Server:** API REST sviluppate con Spring Boot per la generazione degli esiti e la validazione delle puntate.

## Tecnologie utilizzate
- **Backend:** Java, Spring Boot, Maven
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
